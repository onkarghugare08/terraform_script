# Terraform Scripts

This repository contains my hands-on Terraform practice as I learn **Infrastructure as Code (IaC)** and AWS infrastructure concepts for DevOps.

## Learning Areas

- **`terra-aws-infra/`** — Practice organizing Terraform configuration for AWS infrastructure.
- **`terraform-modules/`** — Learn how to structure and reuse Terraform modules.
- **`EKS-cluster/`** — Explore Terraform configuration related to Amazon EKS and Kubernetes infrastructure.

## What I'm Learning

- Writing infrastructure as code with Terraform
- Organizing Terraform configuration files
- Understanding reusable modules
- Practicing AWS infrastructure concepts
- Exploring infrastructure for Kubernetes with Amazon EKS

## Purpose

This is a learning repository for practice, experimentation, and documenting my progress with Terraform. The configurations are for educational purposes and should be reviewed and adapted before being used in any real environment.
